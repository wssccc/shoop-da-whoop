# 纸牌接龙 · 解法搜索

本文件记录给定初始状态的求解结果，以及求解器的使用方法。

> 解法由本仓库自带的解搜索器（`games/solitaire/tools/solver/`）自动生成，
> 并经过重放校验（`solve.js --verify`：逐步校验每步合法性，终局满足胜利条件）。
> 求解器是 `src/game/`（rules.ts / engine.ts）规则的 1:1 移植：数字牌按
> 递减 + 颜色交替叠放、整叠移动容量不限、安全数字自动入槽、同色四龙全暴露可收龙。
> 搜索出的原始路径会先经 `compress.js` 做可逆性驱动的四通道压缩（删除
> "回到相同状态"的环段、合并"先停车再取走"的绕路、删除逆操作合法的
> 可逆对与单步绕路），每次改写都重新验证合法且终局胜利，因此下方步骤
> 不含废操作。可逆性理论的形式化规格（定义/定理/算法）见文末附录。

## 求解器使用说明

工具位于 `games/solitaire/tools/solver/`，零依赖 Node ESM，规则 1:1 移植自
`src/game/`。**完整技术文档见 [`tools/solver/docs.md`](../tools/solver/docs.md)**
（架构、数据模型与方向约定、搜索/压缩/关键步算法、性能与限制）；
**可逆性理论与优化解规格见文末附录**。

| 文件 | 职责 |
| --- | --- |
| `rules.js` | 规则引擎：叠放/连牌/合法目标/自动归位/收龙/胜利判定 + 状态键 |
| `parse.js` | 解析布局文本（每行从左到右 = 牌堆底 → 牌堆顶；校验 40 张牌） |
| `search.js` | DFS + 转置表 + 前瞻启发式 + beam 迭代求解器 |
| `compress.js` | 输出前压缩：四通道去重（环/停车/逆对/单步可逆）到不动点，逐次重放验证 |
| `format.js` | 中文步骤格式化 + ★关键步标记 + 重放校验 |
| `solve.js` | CLI 入口（默认启用去重，`--no-compress` 关闭） |
| `layout.txt` | 布局输入（与上文相同） |
| `rules.test.js` / `compress.test.js` | 规则 / 去重单测（`node --test`） |

运行：

```bash
cd /workspaces/shoop-da-whoop
node games/solitaire/tools/solver/solve.js          # 求解并打印中文步骤（自动去重 + ★标记）
node games/solitaire/tools/solver/solve.js --verify # 追加重放校验
node games/solitaire/tools/solver/solve.js --json   # 输出 JSON 步列表
node --test "games/solitaire/tools/solver/*.test.js"  # 全部单测
```

自定义布局：编辑 `games/solitaire/tools/solver/layout.txt`（8 行 × 5 个 token，
每行一列，从左到右 = 牌堆底 → 牌堆顶（可抓取），最外层在行最右边），再运行 solve.js 即可。

> 备注：本局难度较高（12 张龙牌 + 仅 3 空闲格），搜索启发式 + 四通道压缩后
> 为 46 步玩家操作（另有 25 步自动归位）。

## 附：可逆性理论与优化解（规格）

> 本节为求解器"找局部最优关键解"（无可删除的可逆绕路）的正式规格；
> 实现见 `rules.js :: isReversibleStep`、
> `compress.js`（四通道压缩）、`search.js`（可逆性启发式）。

### 记号与模型

| 记号 | 含义 |
| --- | --- |
| $\mathcal{S}$ | 全部合法棋盘状态的集合（tableau × freeCells × foundations × flowerSlot） |
| $\mathcal{A}$ | 全部合法**用户操作**的集合（`move` / `collect`）；自动归位不属于用户操作 |
| $\gamma: \mathcal{S} \to \mathcal{S}$ | **自动归位级联**：反复执行"花→花牌位、安全数字→终局槽"直到不动点（确定性、强制、不可逆） |
| $\delta(s, a)$ | **一步转移**：$\delta(s,a) \triangleq \gamma(\mathrm{apply}(s,a))$；搜索图的节点即 $\delta$ 的像 |
| $s_0, s^*$ | 初始状态；胜利状态（三色终局槽 1..9 全满、花入位、场上无龙） |
| $R_a$ | 操作 $a$ 携带的牌叠（run；$R_a[0]$ = 底牌，即与落点直接接触的牌） |
| $p_a, q_a$ | 操作 $a$ 的源位置与目标位置（列 / 空闲格 / 终局槽 / 花牌位） |

**解**：操作序列 $\sigma = \langle a_1, \dots, a_n \rangle$（$a_i \in \mathcal{A}$）满足
$\delta(\cdots\delta(\delta(s_0, a_1), a_2)\cdots, a_n) = s^*$。
$\sigma$ 诱导的**状态轨迹** $\tau(\sigma) = \langle s_0, s_1, \dots, s_n \rangle$，
其中 $s_i \triangleq \delta(s_{i-1}, a_i)$。

### 可逆性

**定义（逆操作）**。$a$ 将 $R_a$ 从 $p_a$ 移至 $q_a$，其**逆操作** $a^{-1}$
为"将同一牌叠 $R_a$ 从 $q_a$ 移回 $p_a$"。

**定义（可逆操作）**。$a$ 在状态 $s$ 上**可逆**，当且仅当 $a^{-1}$ 在
$\delta(s, a)$ 上是合法用户操作。

> 判定约束：可逆性必须在 $\delta(s,a)$（级联后状态）上**实时**检查，不得
> 依据历史推断——初始发牌允许非法叠放（龙叠数字、同色相邻等），"该牌曾
> 位于此"不构成合法性。run 取 $q_a$ 顶部的 `count` 张（原步实际携带的牌）。

**定理（判定准则）**。设 $\delta(s,a)$ 中源列 $p_a$ 的顶牌为 $u$（列空则
$u = \varnothing$），则

$$
a \text{ 在 } s \text{ 上可逆} \iff
\begin{cases}
a = \text{collect} \;\lor\; q_a \in \{\text{终局槽},\, \text{花牌位}\} & \Rightarrow \text{否} \\[2pt]
p_a = \text{空闲格} & \Rightarrow \text{是} \\[2pt]
u = \varnothing & \Rightarrow \text{是} \\[2pt]
\mathrm{canStack}(R_a[0],\, u) & \Rightarrow \text{是} \\[2pt]
\text{其余（}u\text{ 为龙/花/同色/rank 不符）} & \Rightarrow \text{否}
\end{cases}
$$

其中 $\mathrm{canStack}(x,y) \iff x,y$ 均为数字牌 $\land\; y.\mathrm{rank} = x.\mathrm{rank}+1 \land y.\mathrm{color} \ne x.\mathrm{color}$。

**命题（可逆 ≠ 可撤销）**。$\delta(\delta(s,a),\, a^{-1})$ 未必等于 $s$：
级联可能已将 $p_a$ 新暴露的牌送入终局槽（不可逆进展），"逆操作合法"仅保证
操作层面可回退，不保证状态复原——由压缩层全量重放验证兜底。

**定义（等价）**。$s \equiv s'$ 当且仅当两者在可逆边图中**无向连通**（可逆边
$\{s, \delta(s,a)\}$ 由可逆操作定义，为无向边）。$\equiv$ 是等价关系
（自反 / 对称 / 传递）。

### 优化解

**理论版（关键状态转移序列）**：轨迹 $\tau(\sigma)$ 按等价类合并相邻等价
状态，得互不等价的投影序列。投影删除的恰是纯可逆段；但合并后剩余操作不能
逐段直接继承（端点等价状态与原起点不同，剩余操作在其上未必合法），故为
理想化定义。

**命题（严格关键解不可达）**：存在布局使任何解都含相邻等价状态。反例 =
**必要停车**：$X$ 必须离开 $p$（腾空 $p$ 以移动其下长叠或暴露龙），当时唯一
合法落点为空闲格 $c$，$X$ 稍后才被取走——$a: X \to c$ 可逆（逆操作合法），
但删除 $a$ 会使依赖"$p$ 已腾空"的中间移动失效。

**工程版（局部最优关键解）**：解 $\hat\sigma$ 是局部最优关键解，当且仅当：

1. **合法性**：每步经 `validDropTargets` 校验合法，收敛后终局胜利；
2. **不动点**：不存在下列删除（每个候选须满足"删除后重放仍合法且胜利"）：
   - **单步删除**：删除 $a_i$（$a_i$ 可逆，且 $q_{a_i}$ 之后无人触碰）；
   - **逆对删除**：删除 $(a_i, a_j)$（$a_j$ 与 $a_i^{-1}$ 位置互换且 run 内容
     逐张相等，$q_{a_i}$ 与 $p_{a_i}$ 中间无人触碰）；
   - **停车合并**：$a_i$ 改写为直达 $q_{a_j}$ 并删 $a_j$（$a_j$ 从 $q_{a_i}$
     取走 run，$q_{a_i}$ 中间无人触碰）。

### 压缩算法（`compress.js`）

四通道（环删除 / 停车合并 Case 1 / 逆对删除 Case 2 / 单步可逆删除 Case 3），
`removeCycles` 与 `compactDetours` **交替循环到总不动点**；每次候选改写先
`replayCheck` 全量重放（逐步 `validDropTargets` + 终局 `isWin`）验证，通过才
接受；输出后重跑两阶段断言零改动（**不动点自检**，失败回退原始解、CLI
退出码 3）。

**定理**：终止（步数单调递减）；正确性（输出合法且胜利、处于不动点）；
单调性（$\mathrm{after} \le \mathrm{before}$）。复杂度最坏 $O(n^3)$ 步级
重放（$n$ = 解长度），实测 $n \approx 50$ 时 ~12ms。

**指标 `reversibleLeft`**（CLI"｜残留可逆步：Y"）：重放输出解，统计逆操作仍
合法但无法删除的用户步数 = **必要绕路**数，量化理论版与工程版的偏差。

### 搜索启发式（`search.js`）

一阶前瞻打分追加可逆性惩罚：

$$
\mathrm{score}'(m) = \mathrm{score}(m) - 40\,|\gamma(\mathrm{apply}(s,m))|
 - 15\,[m=\text{collect}] - 12\,\Delta_{\text{exposed}} + 2\,[m \text{ 可逆}]
$$

$+2$ 惩罚把可逆绕路排在不可逆进展之后，又不把必要停车挤出 beam。

### 保证与局限

**保证**：输出合法且胜利（重放逐次验证 + `--verify` 全量重放）；输出处于
两阶段不动点；压缩单调。

**局限**：局部最优而非全局最优（贪心顺序可能漏删，如逆对 run 内容不等但
删除合法的部分回移场景）；必要绕路必然残留（命题）；理论版"无相邻等价
状态"不可达；最短关键解（等价类商图最短路径）列为未来工作。
