# KeyFlow — 产品文档

## 1. 产品概述

**KeyFlow** 是一款**单用户**打字训练应用：首次运行引导建档，之后直接进入主菜单，
提供课程练习、测试、进度报告、速度/准确率图表与选项设置。UI 采用 Windows 98
复古桌面风格（98.css），交互现代化（模态对话框、全局通知、屏幕转场、表单语义）。

- **定位**：打字教学与练习工具（个人训练）
- **目标用户**：打字初学者、需要提升打字速度/准确率的用户
- **平台**：任意现代浏览器（Chrome/Firefox/Edge/Safari），无需安装
- **数据**：本地存储（localStorage），不联网、不上传

## 3. 快速开始

### 3.1 运行

KeyFlow 已纳入 Shoop Da Whoop 的 Vite MPA 单仓构建，从仓库根目录运行：

```bash
npm run dev            # 开发：http://localhost:5173/games/keyflow/
npm run build          # 生产构建（含 plugin-legacy 双包）
npm run preview        # 预览构建产物
```

> 也可直接构建后由任意静态服务器托管 `dist/`。

### 3.2 首次使用流程

1. **启动画面**：按任意键
2. **档案设置**：输入姓名（如 `Alice`），日期默认今天（可改）
3. **介绍**：3 页操作说明（可跳过）
4. **初始测试**：按提示输入短文（可跳过）
5. **主菜单**：之后每次启动直接进入主菜单（训练数据保留）

### 3.3 按键速查

| 键 | 作用 |
| --- | --- |
| `↑` / `↓` / `W` / `S` | 菜单上下移动 |
| `Enter` / `空格` | 确认选择 |
| `Esc` | 返回上级 / 结束打字会话 |
| 字母/数字/符号键 | 打字练习输入 |
| 鼠标 | 点击菜单项 / 按钮（补充操作） |

## 4. 核心交互说明

### 4.1 打字练习界面

```text
┌──────────────────────────────────────────┐
│  Home Key Lesson                          │
│  ┌────────────────────────────────────┐  │
│  │ fdsa ;lkj fdsa ;lkj fdsa ;lkj ...  │  │ ← 课程文本（白色画布）
│  │ ▲                                   │  │ ← 红色指针（字符 DOM 对齐）
│  └────────────────────────────────────┘  │
│  fdsa ;lkj                               │ ← 已输入内容
│  Speed: 23 WPM   Accuracy: 100%   Keys: 9│ ← 实时统计
│  Esc -> Return to Menu                   │
└──────────────────────────────────────────┘
```

- **指针**：红色 ▲ 指示下一个要输入的字符，基于字符实际 DOM 位置对齐（折行不漂移）
- **已完成**：灰色显示；**当前字符**：蓝底反白
- **光标与进度**：输入行闪烁块光标；`Line X/Y` + 完成百分比进度条
- **错误**：按错时该字符在输入行红显（不卡住，指针继续前进），错误计入准确率与每键统计
- **完成**：输入完整个文本自动结束，或随时按 `Esc`

### 4.2 统计口径

| 指标 | 公式 | 说明 |
| --- | --- | --- |
| WPM | (正确 + 错误 − 2×行数) ÷ 5 ÷ 分钟 | 参考公式 |
| 终身平均 WPM | (总字符 + 总正确 − 2×总错误) ÷ 5 ÷ 总分钟 | 参考公式，惩罚错误 |
| 准确率 | 正确 ÷ (正确 + 错误) × 100 | 参考公式 |
| 每键 WPM | 该键正确数 ÷ 5 ÷ 该键用时 | 驱动 Best Keys / Keys to Work on |
| 掌握判定 | 尝试 ≥ 30 且准确率 ≥ 80% 且每键 WPM ≥ 15 | 参考阈值 |
| 课程推进 | 键集中未掌握键 < 4 → 引入新键 | 引擎规则 |
| 课程长度 | drills 数（默认 10，可选 5/10/15/20） | 每课行数 |

### 4.3 目标设定

- **初始测试后**：速度目标 = 当前速度 + 10（20~120 范围）；准确率目标 = 90%
- **练习目标**：Beginner 30 分钟/周，Two-finger 45，Touch 60（按经验水平）
- **手动调整**：Options → Change speed goal / Adjust practice goal / Change accuracy goal
- **周对比**：主菜单欢迎文案 + 进度报告展示本周练习量 vs 目标

## 5. 数据与隐私

| 项目 | 说明 |
| --- | --- |
| 存储位置 | 浏览器 localStorage（本机） |
| 存储内容 | 单个用户档案（训练历史、目标、每键统计、会话日志） |
| 网络 | 零请求，完全离线可用 |
| 清除 | 浏览器清除站点数据，或 Options → Reset profile |
| 备份 | 复制 `localStorage` 中 `keyflow_profile_v2` 键值即可迁移 |

### 用户档案字段

姓名、上次练习日期、经验水平、速度/练习/准确率目标、drills 数、当前速度（WPM）、
当前准确率、累计练习分钟、52 周速度/准确率/练习分钟历史、每键统计（64 键）、
会话日志（最近 200 条）、当前课程键索引、首次引导完成标记。

## 6. 设计取舍

### 6.1 核心机制

- 菜单结构与导航方式（方向键 + Enter + Esc）
- 打字练习交互（指针、输入行红显、实时统计）
- WPM / 准确率计算口径（5 字符 = 1 词）
- 课程体系（Home Key → 全键盘渐进）
- 初始测试 → 目标设定流程
- 52 周进度记录（速度 / 准确率 / 练习分钟）+ 按会话图表
- 键盘优先 + 鼠标 / Tab 双通道导航

### 6.2 未提供的功能

以下能力本产品不提供（机制说明见 `design.md` §9）：

| 功能 | 原因 |
| --- | --- |
| 多学生注册 / 学生选择 / 删除学生 + 全体汇总报告 | 单用户：档案即应用本身 |
| 教师模式（密码门 / 教师菜单 / 加密模拟） | 无教学管理场景 |
| Disk Test（自定义测试文件） | 测试文本内置，浏览器无文件 IO |
| 街机游戏（Letter Invaders）与词库 | 与「练习工具」定位不符 |
| 静态词表课程 | 课程文本由频率表驱动的运行时生成 |
| 双人模式 | 单用户 |
| 音效 / 蜂鸣 | 保持静默（浏览器音频自动播放策略） |

## 7. 常见问题（FAQ）

**Q: 为什么 WPM 显示很高（如 400）？**
A: 测试时快速输入且时间极短导致。真实使用（正常速度输入 1 分钟以上）数值合理。

**Q: 如何重置训练数据？**
A: Options → Reset profile（有确认对话框），或清除浏览器站点数据。

**Q: 数据会丢失吗？**
A: 数据存 localStorage，清除浏览器站点数据会丢失；建议定期备份。

**Q: 支持中文界面吗？**
A: 当前为英文界面（与经典打字软件一致）。

**Q: 可以离线使用吗？**
A: 可以。所有资源本地加载，无需网络。

## 8. 已知限制

1. **测试文本内置**：Practice Test 用当前课程键集生成，All-keys / Keypad 用内置文本，不支持导入自定义文本
2. **多标签页**：同一浏览器多标签打开时数据以最后写入为准
3. **移动端**：桌面优先设计；触屏可点按菜单/按钮，打字仍建议物理键盘
