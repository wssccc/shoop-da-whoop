# 纸牌接龙 · 游戏规则

## 1. 游戏概述

**游戏名称**：纸牌接龙（Solitaire）  
**类型**：单人纸牌接龙（Solitaire / Patience）  
**平台**：HTML5 网页，适配桌面与移动端  
**原型**：基于经典 FreeCell（空当接龙）机制，融入东方主题元素

**游戏目标**：将所有数字牌按顺序送入终局槽，将花牌归位，并收服所有龙牌。

---

## 2. 牌组构成（共 40 张）

| 牌型 | 数量 | 属性 | 视觉特征 |
| --- | --- | --- | --- |
| **数字牌** | 27 张（3 种颜色 × 1~9） | 分三种颜色（红、黑、绿），带数字 1~9 | 数字 + 颜色标识 |
| **龙牌（Dragon）** | 12 张（3 种颜色 × 4 张） | 无数字，不可叠放 | 雀牌字样按颜色区分（红=中、黑=萬、绿=發），收纳后显示 🐙 |
| **花牌（Flower）** | 1 张 | 无数字，不可叠放 | 花朵图案 ✿ |

**三种颜色（阴阳双色体系）**：红色（阳）、黑色（阴）、绿色（调和色）。

---

## 3. 桌面布局

```text
┌──────────────────────────────────────────────────────┐
│  [空闲格1] [空闲格2] [空闲格3]  [🐉收龙]  [花牌位]  [终局·红] [终局·黑] [终局·绿] │
│                                                      │
│  [列1] [列2] [列3] [列4] [列5] [列6] [列7] [列8]     │
│   ...    ...    ...    ...    ...    ...    ...    ...  │
└──────────────────────────────────────────────────────┘
```

| 区域 | 数量 | 功能 |
| --- | --- | --- |
| **桌面列（Tableau）** | 8 列 | 主游戏区，牌面朝上叠放。每列开局 5 张 |
| **空闲格（Free Cells）** | 3 格 | 临时存放单张任意牌；龙牌归宿 |
| **收龙按钮** | 1 个 | 一键收纳同花色全部暴露的龙牌 |
| **花牌位（Flower Slot）** | 1 格 | 花牌专属位置，顶部正中 |
| **终局槽（Foundation）** | 3 槽 | 按颜色顺序从 1→9 堆放数字牌 |

## 4. 核心规则

### 4.1 数字牌叠放规则（Tableau → Tableau）

- 只能将牌放到 **比它大 1 且不同颜色** 的牌上
- 形成 **递减、交替颜色** 的序列
- 例：`红3 → 黑4 ✓`，`红3 → 红4 ✗`，`红3 → 黑5 ✗`

### 4.2 整叠移动

- 满足 **递减且颜色交替** 的整叠牌可以 **整体拖动**
- **容量不限**：任意长度的合法序列均可一次性搬到目标列，无需消耗空闲格或空列作为中转
- **限制**：整叠牌不能整体放入空闲格或终局槽（这两处仅收单张）

### 4.3 可移动目标

数字牌（单张或整叠）可移到：

1. **空白桌面列**（任何牌均可放入空列）
2. **比它大 1 且不同颜色的牌顶**
3. **左上角空闲格**（仅限单张数字牌或单张龙牌/花牌）
4. **右上角终局槽**（仅限单张数字牌，需满足顺序条件）

### 4.4 空闲格规则

- 每格最多存放 **1 张牌**
- 可用于临时存放任意牌（数字牌、龙牌、花牌均可）
- 龙牌收服后，空闲格会 **永久锁定** 为龙牌收纳格，不可再用于其他牌
- 空闲格中的牌可随时移出

### 4.5 终局槽规则

- 每个终局槽对应 **一种颜色**（红、黑、绿）
- 必须从 **1** 开始，按 **1 → 2 → 3 → … → 9** 顺序堆放
- 牌一旦进入终局槽 **不可再移出**

## 5. 特殊牌机制

### 5.1 龙牌（Dragon）

| 属性 | 规则 |
| --- | --- |
| 基本限制 | **不可叠放到任何牌上**，也不能被叠放（不能作为目标牌） |
| 释放条件 | 必须处于 **牌列最顶端**（不被任何牌压住） |
| 收纳机制 | 当 **同一颜色的 4 张龙牌全部暴露**（均在列顶或空闲格中）时，**收龙按钮** 亮起；点击后可一键将 4 张龙牌收纳至一个空闲格 |
| 资源占用 | 收纳后该空闲格 **永久锁定**，不可再用于其他牌 |
| 手动移动 | 单张龙牌可拖入空闲格暂存 |

**策略要点**：龙牌是最大的"路障"，释放龙牌需要消耗空闲格资源。过早占用空闲格 → 龙牌无处收纳 → 死局可能。龙牌不可被压住（下方不能有牌），否则无法移动。

### 5.2 花牌（Flower）

| 属性 | 规则 |
| --- | --- |
| 基本限制 | **不可叠放**，不能放到其他牌上 |
| 自动行为 | 一旦不再被压住（处于列顶或空闲格中），**自动飞入顶部正中的花牌位** |
| 胜利要求 | 花牌必须进入花牌位才算胜利 |

---

## 6. 自动归位机制（Auto-Move）

系统会自动将符合条件的牌送入终局槽或花牌位，无需玩家手动操作：

| 条件 | 行为 |
| --- | --- |
| **花牌暴露** | 花牌一旦处于可移动状态，立即自动飞入花牌位 |
| **数字牌安全入槽** | 当某张数字牌满足"安全"条件时，自动飞入对应颜色的终局槽 |

**安全（Safe）条件**：一张数字牌可自动入槽当且仅当：

1. 它确实是该颜色终局槽的下一个所需数字
2. **所有其他颜色的终局槽都已达到至少 `rank - 1` 的位置**

例：`红5` 可自动入槽当且仅当：

- 红槽已完成到 4
- 黑槽已完成到 ≥ 4
- 绿槽已完成到 ≥ 4

此机制确保自动归位不会阻断后续牌序。

**设计意图**：减少玩家机械操作，聚焦策略决策。

---

## 7. 胜利条件

达成以下 **全部** 条件即获胜：

1. ✅ **所有 27 张数字牌** 按颜色、顺序（1→9）堆满 3 个终局槽
2. ✅ **花牌** 进入顶部正中的花牌位
3. ✅ **所有 12 张龙牌** 全部收纳至空闲格（占用 1 个空闲格，且被锁定）

胜局计数增加，可触发成就。

## 8. 操作方式

### 鼠标/触控

| 操作 | 方式 |
| --- | --- |
| **移动牌** | 点击并拖拽牌到目标位置 |
| **收龙** | 点击 🐉 **收龙** 按钮（按钮呈高亮时才可用） |
| **横屏全屏**（移动端） | 点击 ⛶ **全屏** 按钮（桌面端该按钮隐藏，用 `F` 键代替） |

### 键盘快捷键

| 按键 | 功能 |
| --- | --- |
| `N` | 新游戏 |
| `U` / `Z` | 撤销上一步 |
| `M` | 静音/取消静音 |
| `C` | 收龙（按钮高亮时有效） |
| `F` | 横屏全屏/退出全屏 |

### 撤销

- 支持多步撤销，默认上限 **300 步**（超出后自动丢弃最早快照）
- **可回退任何操作**：每次用户操作（移动牌、收龙）执行前都会 `snapshot()` 保存全盘快照，因此撤销同样能回退进入终局槽 / 花牌位 / 收龙的牌
- 撤销栈仅存于内存，**页面刷新后不保留**（但当前棋盘本身会从存档恢复）

## 10. 策略提示

### 资源管理三角

```text
        空闲格（3 个）
       /      |      \
  临时存放   龙牌归宿   解锁列空间
```

### 关键决策点

1. **是否手动提前入槽？**
   - 利：腾出桌面空间，解锁被压住的牌
   - 弊：不可逆，可能阻断后续叠放路径

2. **何时收龙？**
   - 需确保 4 张同色龙牌全部暴露
   - 需确认有一个空闲格可用
   - 收龙后该空闲格永久锁定——确保不再需要该格做中转

3. **空列的利用**
   - 空桌面列可作为"临时中转站"来重组牌序

4. **颜色分布意识**
   - 三种颜色的数字牌相互交错，规划移动时注意每种颜色的分布
   - 终局槽要求按颜色独立完成 1→9

## 11. 与传统 FreeCell 的差异

| 维度 | 传统 FreeCell | 纸牌接龙 |
| --- | --- | --- |
| 牌数 | 52 张 | 40 张 |
| 颜色/花色 | 4 种花色（♠♥♣♦） | 3 种颜色（红、黑、绿） |
| 空闲格 | 4 个 | 3 个 |
| 终局槽 | 4 个（按花色） | 3 个（按颜色） |
| 特殊牌 | 无 | 龙牌 12 张、花牌 1 张 |
| 暗牌 | 无 | 无 |
| 整叠移动 | 受空闲格/空列数量限制（super-move） | **不限容量** |
| 死局率 | 极低 | 极低 |

---

## 12. 设计哲学

- **极简主义**：40 张牌、3 种牌型、2 条核心规则，创造深度策略
- **东方美学**：龙牌（不可驾驭，需"收服"）、花牌（禅意，自动归位）、阴阳三色体系
- **休闲节奏**：单局 5~15 分钟，适合工作间隙放松
